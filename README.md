# AL-TAS System

AL-TAS is a full-stack business operations platform for retail, POS, inventory, sales, HR, payroll, accounting, and stock management.

## Tech Stack

- Frontend: Vite + React
- Backend: Express + Node.js
- Database: PostgreSQL + Prisma ORM
- Auth: JWT + bcrypt

## Features

- POS and sales workflows
- Inventory and stock control
- Product, branch, and location management
- HR, payroll, and attendance modules
- Accounting and expense tracking
- Returns, promotions, and motorbike operations
- Seeded demo accounts for role-based access
